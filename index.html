How this works in production:

When an expense is submitted via API or ERP, it publishes to Google Cloud Pub/Sub. Pub/Sub pushes the payload directly to the Vertex AI Reasoning Engine using --push-no-wrapper. Claims ≥ $100 pause in the ADK session state until a manager reviews them on this dashboard.
